# mini-snaptik

A simple web-based project inspired by SnapTik for working with TikTok links.

## Features

- Simple and responsive interface.
- TikTok link input.
- Minimal and easy-to-use design.

## Tech Stack

Sesuaikan bagian ini dengan teknologi yang digunakan project.

## Getting Started

### 1. Clone Repository

```bash
git clone https://github.com/xx1ndr/mini-snaptik.git
cd mini-snaptik
```

### 2. Install Dependencies

```bash
npm install
```

### 3. Run Development Server

```bash
npm run dev
```

Open the local URL shown in your terminal.
